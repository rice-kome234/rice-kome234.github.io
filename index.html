02

Archetype ECS Module Library

3年生で制作した、C++20 module形式のArchetype ECSです。 Entity、Component、Archetypeを分け、指定したコンポーネントを持つEntityへ ラムダ式で処理を行える仕組みを作りました。

コンポーネント構成は std::bitset のシグネチャで管理し、 型の組み合わせをビット列として見られるようにすることで、Archetypeの一致判定を理解しやすくしました。

  • C++
  • C++20 Module
  • ECS
  • Archetype
  • Bitset
03

C++20 Memory Module Library

2年生で制作した、C++20 module形式のメモリ管理ライブラリです。 import memory; で使える公開インターフェースを意識して、 オブジェクト生成、解放、使用バイト数の取得をまとめました。

std::pmr::memory_resource と組み合わせ、事前に確保したメモリ領域を使うことで、 生成コストを抑える設計に挑戦しています。コメントはDoxygen形式で整理しました。

  • C++20
  • Module
  • PMR
  • Doxygen
04

Console Game / Double Buffer Library

1年生のときに制作したC++コンソールゲームです。 純粋仮想関数を持つ基底クラスを作り、各処理を共通のインターフェースから呼び出す構成に挑戦しました。

Windows.h を利用側で直接扱わない制約の中で、描画のちらつきを抑えるための ダブルバッファ機能を doublebuffer.h としてまとめました。 1年生時点の作品のためマジックナンバーが多く残っていますが、現在は定数化や責務分離を意識して改善しています。

  • C++

  • Double Buffer
